<summary><b>🔍 展开：我的开发哲学（点击展开）</b></summary>
<br/>


> **1. 可读性是第一性能指标。**
> 代码被读的次数是被写次数的十倍，写给下一个人（通常是三个月后的自己）。
>
> **2. 抽象要迟到，不要早到。**
> 三次重复才配拥有抽象，两次只是巧合。
>
> **3. 边界决定架构。**
> 模块之间怎么说话，比模块内部怎么干活重要一百倍。
>
> **4. 别和框架对抗。**
> 顺着数据流走，你省下的力气够再造一个特性。
